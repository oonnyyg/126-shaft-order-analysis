# 角域阶次分析工具

变转速工况下，时间域频谱的谱线随转速漂移，难以直接比较。本工具把独立采集的
轴角记录与振动记录对齐到角域，按"每转"重采样并计算阶次幅度，仅使用
Python 标准库。

## 输入

两份 CSV（UTF-8，带表头）：

- 角度记录：列 `time,angle`，时间秒、累计转角弧度（不折回一圈）。
- 振动记录：列 `time,vibration`。

要求：所有数值有限；两份时间各自严格递增；累计转角严格递增。

## 方法

1. 取两份记录时间范围的交集，按累计角度的 2π 整数倍划分完整转；
   首尾不足一转的部分舍弃，不外推、不补零。无完整转时报告明确原因
   （时间范围不重叠 / 不足一个完整转）。
2. 每转按配置的正偶数点数 `N` 等角度采样（含起点、不含终点）：
   先在 `angle -> time` 上反查采样时刻，再在振动记录上线性插值，
   不按原始记录序号等分。
3. 每转采样去均值后做 DFT，阶次 `k` 的**峰值幅度**定义为
   `A_k = 2 * |X_k| / N`。阶次 `k` 表示"每转 k 次"的周期成分，
   只接受正整数且严格小于 `N/2`（奈奎斯特限制）。不加窗、不算功率谱。
4. 逐转报告平均转速（`60 / 转周期`，rpm）与各阶次幅度；
   跨转按各阶次幅度的**均方根**汇总。
5. 另对跨转**同步平均波形**（逐角度点对齐平均后去均值）计算阶次幅度。
   同步平均会保留与转角锁相的成分、抑制随机噪声，其结果与逐转幅度
   的均值/RMS 一般不同，不能互相替代。

## 使用

```bash
python -m shaft_order_analysis \
    --angle-csv angle.csv --vibration-csv vib.csv \
    --samples-per-rev 64 --orders 1,2,3 \
    --resampled-out resampled.csv --report-out report.json
```

输出：

- 重采样 CSV：`revolution, angle_rad, time_s, vibration`，每行一个角域采样点。
- JSON 报告：配置、空结果原因、逐转 `mean_rpm` 与各阶次幅度、
  `rms_amplitudes` 汇总、同步平均波形及其阶次幅度。

## 测试

```bash
python -m unittest discover -s tests
```

覆盖：线性升速（chirp）信号的阶次恢复、两份记录不同时间网格、
直流偏置去除、不足一转/无重叠的空结果、非法数据校验、CLI 端到端。
